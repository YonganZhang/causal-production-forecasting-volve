## 领域全景

**任务分布**：16 篇中 7 篇纯时序预测（DLSTM / LSTM+PSO / ARIMA-LSTM / CNN-LSTM-SA / ARIMA-LSTM-Prophet / NARX / Bakken-DNN）；5 篇物理代理与系统辨识（CRM×3、INSIM-FT、CRM 综述）；3 篇模拟器内最优控制（SAC-DRL、GLSADE、优化综述）；仅 1 篇（Chernozhukov DML）是真因果推断且不属油气领域。**领域内零篇在真实生产数据上做过因果效应估计。**

**口径**：预测流派普遍用体积或累计量（DLSTM 直接预测累计产油）；CRM/INSIM 严格用速率且带守恒约束，是口径最干净的一支。

**验证范式**：预测流派清一色「单次 80/20 时序切分 + RMSE/MAPE + 与另一个 ML 模型比」；代理与控制流派的 ground truth 全部是数值模拟器自身（既当环境又当裁判）；CRM 靠「与流线/示踪剂/断层定性一致」。全部 16 篇无一有真实干预对拍。

**干预语义**：所有声称「考虑操作变量」的工作，实际只是把油嘴/注水/开井时长当特征喂进条件期望 E[y|x]，无 do 算子、无反事实、无可识别性讨论，却在结论写「可指导工程师调整方案」。

**结构性空白**：识别性诊断（treatment 还剩多少条件外生变异）、物理过约束检验（估计量是否满足已知守恒或单调关系）、平凡基线——三者同时缺失。

## 这批文献的通病

按出现频率排序，我们必须逐条避开：

**1. 平凡基线系统性缺失（16 篇里 0 篇跑 persistence）。** DLSTM、CNN-LSTM-SA、Bakken-DNN、NARX 全部只跟别的 ML 模型比；CNN-LSTM-SA 的 8 个对照全是 ML。ARIMA/LSTM/Prophet 那篇自报 LSTM 跨井平均 R²=−2.05（即输给常数均值），却引一篇药理学文献辩解「R² 不适用于非线性回归」而不撤回结论。→ 我们每张表第一行必须是 persistence / 历史均值 / 恒等式基线，且允许它赢。

**2. 记账恒等式与自回归捷径。** CNN-LSTM-SA 把含水率与产水量同时当输入去预测产油量，而 Qo = Qw(1−fw)/fw 是解析恒等式，两个输入直接把标签算出来；DLSTM 预测「累计产油」并用一阶差分把 C_{t−1} 当免费兜底；NARX 输入含 6 个滞后产量项 + 同期井口压力，R²>0.9 完全落在 persistence 射程内。→ 与本项目 2026-08-06 撤稿同类。我们的目标量必须是速率或比值口径。

**3. 关井/停机被当噪声抹掉。** LSTM+PSO 用 LOF 把离群点替换成前后均值（关井日必被判离群），且在切分前做、测试集也被清洗；Bakken-DNN 全文不提停机、直接拿未按开井时间归一化的累计体积当标签；CRM / INSIM / RL 三支根本没有 uptime 概念。→ 我们必须把关井显式建模为状态（甚至当成 treatment），不是缺失也不是 0。

**4. 预处理泄漏与测试集选型。** DLSTM 在切分前做 5 点滑动平均、GA 适应度就是测试集误差；LSTM+PSO 的 min-max 用全序列统计；NARX 的特征消融在 5 个神经元档里互有胜负，只取有利那档下结论；ARIMA/Prophet 那篇按「哪组季节性讲得通故事」选超参。

**5. 把观测关联直接读成干预效应。** LSTM+PSO 写「设定未来油嘴即可预测未来产量」，而它自己描述的油嘴调整正是被过去产量反向决定的（内生反馈）；CRM 把回归权重 f_ij 当因果连通性，而 CRM 综述自己承认 f_ij 反映的是压力支撑、与流线分配因子在部分井对上显著不符；Bakken-DNN 用只有投产后才测得的「返排液回收率」去做压裂设计建议。

**6. 统计力度不足却下强结论。** 单井单折、无随机种子重复、无置信区间是常态。ARIMA/LSTM/Prophet 的方法排序来自 n=1 口井，而它自己第 5 节 65 口井给出相反排序却没回头修正。

**7. 代理与控制流派的闭环自证。** SAC-DRL 与 GLSADE 的真值全部来自 Eclipse 自身；SAC 无多种子、无地质不确定性、无 base case / reactive control 平凡策略对照，且状态用全网格饱和度+压力（现场根本不可观测）。

**8. 不做识别性诊断。** CRM 系列都口头承认「注入信号必须富才可辨识」，却没有任何一篇把「treatment 还剩多少条件外生变异」量化出来。这恰是我们能以极低成本填的空，也是 P1/P3 的核心方法学卖点。

## P1 · 油嘴开度的因果剂量-响应，及其 IPR 物理过约束检验

**计算机范式**：因果效应估计：Neyman 正交矩条件（Robinson partialling-out / 偏线性模型）+ 时间块交叉拟合（block cross-fitting with embargo），nuisance 用梯度提升树。附带一层结构性中介分解，以及一个用测量物理量做的过约束（over-identification）假设检验。不是预测，不是最优控制。

**科学问题**：在给定井况状态下，把油嘴开度提高一个百分点，对该井的瞬时产液速率与产油速率的因果效应有多大；这个估计量是否满足流入动态方程（IPR）q = J·Δp 施加的过约束？

### 数学形式化

**符号**。井 i∈{F-1C,F-11,F-12,F-14,F-15D}，日 t。H_{it}=ON_STREAM_HRS。速率口径（除掉记账项）：
q^L_{it} = (V^o_{it}+V^w_{it})/H_{it}（Sm³/开井小时），q^o_{it}=V^o_{it}/H_{it}，f^w_{it}=V^w/(V^o+V^w)。
处理 D_{it}=AVG_CHOKE_SIZE_P ∈(0,100]。状态 X_{it} = {q^L,q^o,f^w,p_wf,WHP,WHT,D} 在滞后 1,2,3,7 天的取值 ∪ {累计产油, 时间指标}。井底压力 p_wf=AVG_DOWNHOLE_PRESSURE。

**结构模型（偏线性，逐井）**：
  q^L_{it} = θ^L_i · D_{it} + g_i(X_{it}) + U_{it},  E[U|D,X]=0
  D_{it}   = m_i(X_{it}) + V_{it},               E[V|X]=0

**Neyman 正交 score**（对 nuisance η=(ℓ_i,m_i) 一阶不敏感，ℓ_i(X)=E[q^L|X]）：
  ψ(W;θ,η) = ( q^L − ℓ_i(X) − θ·(D − m_i(X)) ) · ( D − m_i(X) )
  θ̂^L_i = Σ_t r^D_{it} r^Y_{it} / Σ_t (r^D_{it})²,  r^D=D−m̂, r^Y=q^L−ℓ̂

**交叉拟合**：把每口井的时间轴切成 K=5 段**连续**区块，第 k 折的 (ℓ̂,m̂) 只在 I_k 之外且距 I_k 边界 ≥ e=20 天的样本上训练（embargo，用以修复 Chernozhukov 的 i.i.d. 假设在序列数据上失效）。方差用 HC 型 σ̂² = Σ r_D²(r_Y−θ̂r_D)² / (Σ r_D²)²，另报 block bootstrap（块长 60 天）与 wild cluster bootstrap（按井聚类，5 个簇，故同时报 CI 与置换检验）。

**中介/结构分解**（解释为何产油速率的朴素估计出现荒谬负号）：由恒等式 q^o = q^L(1−f^w)，在 D 上求导得
  θ^o = (1−f̄^w)·θ^L − q̄^L·θ^{fw}
分别独立估计 θ^L 与 θ^{fw}（同一套 DML），再检验它与直接估计的 θ^o 是否一致。注意这是**效应的分解**，不是把 f^w 当已知未来协变量喂进预测器。

**过约束检验（本提案的核心，独立于任何模型）**。流入动态：q^L = J_i·(p_res,i − p_wf,i)。油嘴只能通过改变井底压力作用于流入端，故在同一油藏状态下必有
  θ^L_i / θ^{Δp}_i = J_i,   其中 Δp = p_res − p_wf，θ^{Δp}_i 用同一 DML 估计。
而 J_i 又可由数据**独立**估出：Ĵ_i = median_t q^L_{it}/(p̂_res,i(t) − p_wf,it)，p̂_res 取关井日实测恢复压力的 365 日中心滚动中位数。
检验统计量 T_i = (θ̂^L_i/θ̂^{Δp}_i − Ĵ_i) / se（se 由 delta 方法 + bootstrap）。H0: T_i=0。

**符号约束（可证伪的物理先验）**：∂q^L/∂D ≥ 0 对所有 i 必须成立。任何给出负号的估计量当场判负。

### 数据映射

**唯一数据源**：`_data/volve_causal_v0.2/daily_production.csv`（清单第 1 节），不依赖任何未加工资产。

**列映射**：D←AVG_CHOKE_SIZE_P（F-1C 746/746，F-11 1163/1168，F-12 3012/3141，F-14 2860/3141，F-15D 978/980）；q^L,q^o,f^w←BORE_OIL_VOL/BORE_WAT_VOL/ON_STREAM_HRS；p_wf←AVG_DOWNHOLE_PRESSURE；X 另含 AVG_WHP_P、AVG_WHT_P、AVG_DP_TUBING。AVG_ANNULUS_PRESS 对 F-1C 只有 17/746，**整列剔除**，不做插补。

**关井日**（ON_STREAM_HRS=0，F-1C 307 天/F-14 332/F-12 218/F-15D 209/F-11 43）：速率无定义 → q^L,q^o 置 NaN，该日**不进入估计样本**；但它作为「昨天/前天是否关井」的滞后状态变量保留在 X 中（关井是重要混淆：关井后重启的产量与常态不同）。关井日的 p_wf 反而有效（63.3% 非空，中位 283.5 bar vs 开井 243.1 bar），单独用于估 p_res。

**缺日**（F-12/F-14 各 85 天，F-11 3，F-15D 2）：先 `asfreq('D')` 把日历补齐使缺日显式为 NaN，滞后特征跨缺日自然变 NaN 并整行丢弃，**绝不 ffill**。

**记账恒等式陷阱：结构上免疫。** 目标是 q^L=体积/开井小时，H 已被除掉；处理是油嘴而非开井时长；X 中不含任何未来信息（全部滞后 ≥1 天）。我们不预测未来 H，也不使用未来 H。这与撤稿那次「用未来开井小时预测日产油体积」是完全不同的量。此外 f^w 作为分子分母同除 H 的比值，对 H 完全不敏感——这是它作为结果变量的额外优势。

**有效样本**：滤掉关井日、缺日、缺 D 或缺 p_wf 后实测 n=5,337 井·天（F-14 2454 / F-11 1049 / F-12 836 / F-15D 683 / F-1C 315）。逐井估计，不做跨井 pooling（清单第 6 条硬限制）。

**已实测的重叠性（positivity）诊断**：D 对滞后状态的块 CV R²=0.880，残差 sd=11.67（总 sd=33.71）→ 条件外生变异占方差 12%，非退化但确实小，必须与估计量一起报告。

### 候选模型

Nuisance 学习器（每个都跑一遍，报跨学习器一致性，这是 DML 原文的验收标准）：HistGradientBoostingRegressor（主力，已跑通）、RandomForest、Lasso（含二阶交互展开）、线性 Ridge 作为退化对照。
实现：DoubleML (Python) 或自写 partialling-out（已有 60 行原型跑通）。
对照估计量：朴素 OLS 斜率、加井固定效应的 OLS、非正交插入式 ML 估计量（用于复现 DML 原文 Fig.1 的失败模式）、不做 embargo 的随机 K 折（用于证明块交叉拟合是必需的，这是本文对 Chernozhukov 的具体扩展）。
异质性扩展（次要）：按含水率分层估 θ^L(f^w)，或用 causal forest / DR-learner 估 CATE。
物理对照：IPR 直接拟合 q^L = J(p_res − p_wf) 的稳健回归。

### 验证方案

五层，前三层完全不依赖未加工资产：

**(1) 平凡基线（强制第一行）**：(a) 朴素 OLS 斜率 dq/dD 无任何控制；(b) 仅加井固定效应；(c) persistence 意义下的对照——用 r_D 与 r_Y 的**同期打乱**版本估 θ（应为 0），作为安慰剂。
**已实测的初步结果**：合并数据朴素斜率 = **−0.084 Sm³/hr 每 % 油嘴**（物理上荒谬——开大油嘴产量下降）；逐井朴素 F-14 = **−1.331**，DML 后 = −0.107（对产油速率）；换成产液速率后 DML 五口井**全部为正**：F-1C +0.587(SE 0.100)、F-11 +0.264(0.055)、F-12 +2.477(0.123)、F-14 +1.247(0.076)、F-15D +0.153(0.025)。即**朴素估计违反物理符号约束，DML 修复了它**——这本身就是一个可发表的、量化的因果推断必要性论证。

**(2) 物理符号约束**：θ̂^L_i ≥ 0 对全部 5 口井。目前 5/5 通过；朴素估计 0/5（合并口径）。这是一个真正会失败的检验。

**(3) IPR 过约束检验（核心独立验证）**：比较 θ̂^L/θ̂^{Δp} 与独立估计的 Ĵ。**已实测**：F-12 6.87 vs 6.20（通过）、F-14 1.95 vs 4.09、F-1C 6.58 vs 0.59、F-15D 0.03 vs 0.11、F-11 −2.36 vs 1.19（符号失败）。通过率与该井关井恢复压力的月数正相关（F-12 与 F-14 的 buildup 覆盖最好，F-11 仅 9 个月）——即检验的失败模式本身可被 p_res 估计质量解释，是一条可追查的诊断链，而不是黑箱。

**(4) 留出期 + 时间稳定性**：把每口井时间轴前 70% 估 θ，后 30% 重估，检验结构参数稳定性（CRM 文献承认 f、τ 时变，我们把这条变成显式检验）。另做 leave-one-well-out：去掉任一口井后结论是否翻转。

**(5) 数值模拟反事实（可选，加分层）**：跑 OPM Flow 的 do(choke) 双臂模拟直接给 ground truth θ。**这层不是关键路径**——即使 Eclipse deck 跑不通，(1)-(4) 已构成完整论证。

### 可行性

**高，且已部分完成。** 本轮已用 `_data/volve_causal_v0.2/daily_production.csv` 跑通完整原型：特征构造、块交叉拟合（K=5，embargo 20 天）、逐井 θ̂ 与 SE、IPR 过约束检验，全部数字见上。单次全流程 CPU 约 3 分钟，无需 GPU。

**额外工作量**：(a) 把原型整理进 `_code/`，复用已有的 windows/splits/evaluate 与配对 bootstrap 模块（清单标注这些「换目标即可复用」）；(b) 多学习器一致性扫描 ≈ 5×现有耗时；(c) block bootstrap 与 wild cluster bootstrap ≈ 1000 次重估，仍在小时级；(d) p_res 估计需要一个更认真的方法（当前是 365 日滚动中位数，粗糙），建议改为对每段关井做压力恢复外推（Horner 型 log 外推），这需要小时级井下压力——**我们只有日均值，所以只能停在日尺度恢复压力的稳健汇总**，这个限制必须写进诚实边界。

**不需要**：井位坐标、测井、PVT、地质模型、经济参数。**卡点**：只有 5 口井 → 井级聚类稳健推断的有效簇数只有 5，必须用置换检验补充而不能只靠渐近 CI；这是必须在论文里明说的限制。预估总工作量 1–2 周到可投稿的实验完成度。

### 新意

**相对这 16 篇有三处实质新意。**
(1) 16 篇里没有任何一篇估计过操作变量对产量的**因果**剂量-响应。LSTM+PSO（10.1016/j.petrol.2019.106682）把油嘴当特征、并在结论暗示可控性，但它学的是观测策略下的条件期望，且油嘴本身被过去产量反向决定；我们直接量化了这个内生性有多大：朴素斜率 −0.084，符号就是错的。
(2) Chernozhukov 的 DML 原文明写数据是 i.i.d.，**不覆盖序列/面板**，随机 K 折在强自相关数据上会让辅助折泄漏主折信息。我们的块交叉拟合 + embargo 是针对性扩展，且我们会用「随机折 vs 块折」的对照把这个泄漏量测出来——这是把该篇的已知缺口变成实证结果。
(3) **用测量物理量做因果估计量的过约束检验，16 篇里一篇都没有。** CRM 靠「与断层定性一致」（错了还有三条备选解释消化掉，不可证伪）；SAC-DRL 用模拟器自己当裁判。我们的 θ^L/θ^{Δp} = J 是一个有明确通过/失败判据、且已经真的失败了 4/5 次的检验。一个能失败的检验才是检验。
诚实说：DML 本身、油嘴当协变量、IPR 方程，三者都不新；新的是把它们拼成一条可证伪的验证链，并在一个公开数据集上给出可复现的失败案例。

### 风险

**最可能失败的地方，按概率排：**
(1) **IPR 过约束检验大面积不通过而我们找不到解释。** 目前 5 口井里只有 F-12 明确通过。若 p_res 用更好的方法后仍不通过，可能说明 θ^{Δp} 的估计不可靠（p_wf 本身是被油嘴同期影响的下游变量，把它当结果没问题，但它的日均值口径混合了开井/关井时段），或者说明存在未观测混淆（井筒结垢、气举变化）。缓解：把该检验的结论定位成「诊断工具」而非「必须通过的门槛」，论文卖点改为「我们给出了第一个可失败的检验，并展示了它在真实数据上何时失败」。
(2) **有效样本量远小于名义 n。** 5337 井·天有强序列相关，块 bootstrap 后 CI 可能宽到覆盖 0。特别是 F-14（数据最多）的 θ^o 估计已经贴近 0。
(3) **重叠性只有 12% 残差方差。** DML 的乘积速率条件 ‖m̂−m‖·‖ĝ−g‖=o(N^{-1/2}) 不可检验，在 12% 残差变异下 θ̂ 对 nuisance 误差更敏感。缓解：多学习器一致性 + 报告 R²(D|X) 作为透明度指标。
(4) **只有 5 个井级簇**，任何跨井的一般化主张都站不住。必须把结论限定为「这 5 口井上的井级效应」。
(5) 若审稿人要求真实反事实，只能退回 OPM Flow，而该路径可行性未验证。

## P2 · 关井作为重复自然实验：停井时长对复产后含水率的因果效应

**计算机范式**：因果效应估计：面板事件研究（event study）+ 连续剂量处理效应，带内建安慰剂（pre-trend placebo）与随机化推断（井内置换检验）；外加一层以**实测恢复压力**为中介变量的中介分析。

**科学问题**：把一口生产井关停 L 天，复产后的含水率与产液指数会发生什么因果变化？这个效应是否完全由停井期间的地层压力恢复所中介，还是存在压力无法解释的近井带水侵机制？

### 数学形式化

**符号**。事件 k：井 i(k)、停井起始日 s_k、停井时长 L_k（连续日数，ON_STREAM_HRS=0 的连续区块长度）。停井期间实测恢复压力峰值 B_k = max_{t∈[s_k, s_k+L_k)} p_wf,it。

**结果量（对开井时长恒等式完全免疫）**：
  Y^{post}_k = median 复产后 7 天的 f^w，  Y^{pre}_k = median 停井前 14 天的 f^w
  ΔY_k = Y^{post}_k − Y^{pre}_k
另设两个结果：产液速率对数变化 log(q^{L,post}/q^{L,pre})，与产液指数 J = q^L/(p_res−p_wf) 的变化。

**安慰剂/去趋势（内建对照）**：定义停井前更早一个等长窗口 Y^{pre2}_k（停井前第 15–28 天），得漂移项
  Δ⁰_k = Y^{pre}_k − Y^{pre2}_k
净效应 ΔỸ_k = ΔY_k − Δ⁰_k。若观察到的跳变只是时间趋势，则 ΔỸ 应为 0。

**剂量-响应（偏线性 + 井固定效应）**：
  ΔỸ_k = τ · log L_k + α_{i(k)} + h(X_k) + ε_k
  X_k = {停井前 14 天的 f^w、q^L、p_wf、油嘴、累计产油、日历时间、复产后油嘴变化 Δchoke_k}
用 DML（正交化 log L_k 对 X_k）估 τ，避免「长停井恰好发生在高含水晚期」这类混淆。

**中介分解**（中介变量 B_k 是**实测**的，不是模型产物）：
  总效应 τ_total : ΔỸ_k = τ_total log L_k + ...
  直接效应 τ_dir : ΔỸ_k = τ_dir log L_k + γ B_k + ...
  间接（经压力）效应 τ_ind = τ_total − τ_dir
在序贯可忽略性下 τ_ind/τ_total 是压力通道占比。该假设强，必须显式声明并做敏感性分析（Imai 型 ρ-敏感性）。

**推断**：井内置换检验——在同一口井内随机重排 L_k 与事件时间的配对，重算 τ，得到 sharp-null 分布；同时报 wild cluster bootstrap（5 个井簇）。

### 数据映射

**唯一数据源**：同一份 daily_production.csv。

**事件提取**：对每口生产井 `asfreq('D')` 后，取 ON_STREAM_HRS==0 的连续区块。**已实测**：F-1C 21 段、F-11 12、F-12 58、F-14 47、F-15D 13、F-5(转产后) 3，共 154 段；要求停井前 14 天至少 5 个有效速率日、复产后 7 天至少 3 个有效日，筛后 **109 个可用事件**（F-12 40、F-14 27、F-1C 15、F-11 11、F-15D 11），其中 **80 个事件有停井期间的实测井底压力**（可做中介分析）。剂量分布：≤1 天 40 段、2–3 天 27、4–7 天 18、8–21 天 17、>21 天 7（最长 76 天）。

**关井日处理（这里关井日不是要丢掉的脏数据，而是 treatment 本身）**：停井区间内速率无定义，不参与任何速率统计；但停井区间内的 p_wf 是**有效且关键**的（实测 63.3% 的关井日有非零 p_wf，中位 283.5 bar，显著高于开井时的 243.1 bar，即真实的压力恢复），用于构造中介变量 B_k。

**缺日处理**：缺日会把一个连续停井区块错误地切成两段或错误地拼接。做法是 asfreq 后把缺日标为独立的第三种状态（既非开井也非关井），任何跨缺日的停井区块打标记并做敏感性（含/不含这些事件各跑一遍）。F-12/F-14 各 85 缺日，影响面必须实测报告。

**记账恒等式陷阱：结构上免疫，且比 P1 更彻底。** 主结果量 f^w = V^w/(V^o+V^w) 是同一天两个体积的比值，开井小时数在分子分母中**精确抵消**，与 H 在数学上完全无关。这意味着即使复产后开井小时不满，f^w 也不受影响。这是我们能找到的对撤稿那条恒等式免疫性最强的目标量。次要结果 q^L 与 J 仍走速率口径。

**已知的残余混淆**：复产时操作者往往同时改油嘴（实测 corr(Δchoke, Δlog q)=0.326），必须把 Δchoke 放进 X；停井原因（计划检修 vs 设备故障）我们没有——`Volve_Reports.zip`(169MB, 未加工) 理论上可交叉核对作业事件，但那是可选的加分项，不是必需。

### 候选模型

DML 偏线性（HistGradientBoosting / RandomForest / Lasso 三套 nuisance 交叉验证一致性）；带井固定效应的 OLS 与稳健回归作透明对照；分箱非参剂量-响应（已有初步结果）；中介分析用 mediation 的回归型分解 + Imai ρ-敏感性；推断用井内置换检验 + wild cluster bootstrap。若要更强：Callaway–Sant'Anna 型交错处理 event study 做动态效应（复产后第 1..30 天的逐日效应曲线），检验效应是瞬时跳变还是缓慢恢复。

### 验证方案

**(1) 平凡基线 / 安慰剂（内建，已实测通过）**：等长的停井前漂移 Δ⁰_k 在所有剂量分箱里的中位数为 0.000 / −0.000 / +0.002 / −0.002 / −0.006 —— **安慰剂全部为零**，说明观察到的跳变不是时间趋势。这是一个真正的负对照，不是修辞。
**(2) 已实测的主效应**：去趋势后的含水率变化中位数，按停井时长分箱：≤1 天 −0.001、2–3 天 −0.003、4–7 天 +0.007、8–21 天 **+0.114**、>21 天 **+0.194**。长停井（≥7 天，n=24）vs 短停井（≤1 天，n=40）：中位 +0.115 vs −0.001，Mann-Whitney **p=0.0032**。即**关井一周以上会造成含水率约 11 个百分点的持续上升**，且剂量-响应单调。
**(3) 独立物理验证（不依赖任何模型）**：机制预测是停井期间重力分异 / 水相窜流进入射孔段。可检验的推论有三条：(a) 效应应随含水率本底上升而增强（水相更连续）；(b) 效应应随复产后时间部分回落（近井水被驱替走）——用逐日 event-study 曲线检验；(c) 停井期间的压力恢复幅度 B_k 应能解释一部分但不是全部效应（中介分析）。三条都可在现有数据上做。
**(4) 留出验证**：用 F-12 与 F-14（事件最多、时间跨度最长）估 τ，在 F-1C / F-11 / F-15D 上做样本外检验；再做 leave-one-well-out。
**(5) 数值模拟（可选）**：OPM Flow 里模拟同一口井的 do(shut-in L 天) 双臂，直接看重力分异是否复现该量级。加分项，非关键路径。

### 可行性

**高。** 事件提取、安慰剂、分箱剂量-响应、Mann-Whitney 全部已在本轮跑通，耗时秒级，纯 CPU。剩余工作：(a) DML 版剂量-响应 + 井固定效应（复用 P1 的代码）；(b) 逐日 event-study 动态曲线；(c) 中介分析 + 敏感性；(d) 置换检验与 cluster bootstrap。预估 1 周。

**卡点**：(1) 有效事件数小——长停井（≥7 天）只有 24 个，跨 5 口井，其中 F-1C 的 21 段停井里 17 段 ≥7 天，效应可能被单井主导，必须做 leave-one-well-out 并报告。(2) 停井原因未知，若长停井系统性地发生在「井已经出问题」之后，则存在选择偏倚；缓解是控制停井前的 J 与 f^w 趋势，并用 `Volve_Reports.zip` 交叉核对（解压 + 检索作业事件，预估 1–2 天，属可选）。(3) 日均压力口径无法做标准的 Horner 压力恢复分析，B_k 只能是粗糙的恢复幅度代理。

**不需要任何未加工资产即可完成主结论。**

### 新意

**这是四个提案里最反直觉、也最没被文献碰过的一个。** 16 篇里对关井的态度只有三种：(a) 当离群点抹掉——LSTM+PSO 用 LOF 把关井日替换成前后均值；(b) 当特征喂进去——ARIMA-LSTM-DP 把「日生产时间」当协变量，并把提升解释成学到了压力恢复动力学，但从未把停井当处理来估效应，也无法区分「学会物理」和「被提前告知哪天关井」；(c) 完全不存在——CRM / INSIM / SAC-DRL 三支没有 uptime 概念。
**没有任何一篇把关井当作一个可重复施加的干预，并去估它对油藏状态的因果后果。** 而在 Volve 上关井极其频繁（F-1C 41% 的日子关井），业界普遍默认「关井只是推迟产量，复产后回到原轨迹」——我们的初步结果直接反驳了这一点：长停井造成 ~11 个百分点的含水率永久性抬升，这是停井的隐性成本，有明确的工程含义（计划检修的排程应把这项成本计入）。
方法上新意中等（event study + 安慰剂 + 中介都是标准件），但**结果量对记账恒等式的天然免疫性**与**实测中介变量的可得性**是这个数据集独有的机会。

### 风险

(1) **效应由单井驱动。** F-1C 贡献了 17 个 ≥7 天的停井，而 F-1C 恰好是关井率 41%、环空压力几乎全缺、井况最差的一口井。若 leave-one-well-out 后效应消失，结论垮掉。这是第一优先要跑的检验。
(2) **选择偏倚。** 长停井可能因井已出水/出砂而发生，则含水率上升是原因而非结果。安慰剂显示停井前 14 天无漂移，这对该假说是不利证据，但 14 天窗口可能太短——需要把安慰剂窗口拉到 60/90 天再验一次。
(3) **复产后油嘴同时改变**（实测 corr=0.326），若操作者在长停井后系统性地开大油嘴，含水率上升可能是油嘴效应。必须在 X 中控制并做分层。
(4) 中介分析的序贯可忽略性假设很强，且 B_k 只有 80 个事件、又是日均压力的粗代理，中介占比的估计会很不稳。
(5) 效应可能是暂态的（复产后几天内回落），那就不是「永久抬升」而是「复产瞬态」，工程含义大幅缩水。逐日 event-study 曲线会直接给出答案，且必须在下结论前先跑。

## P3 · 月尺度注水效应的可识别性审计与分布滞后估计（含 F-5 停注自然实验）

**计算机范式**：因果效应估计（分布滞后 / 脉冲响应函数的正交化估计）+ 可识别性诊断（激励充分性、条件外生变异的量化）+ 结构化物理基线（CRM 作为参数化对照）+ 中断时间序列 / 合成控制（F-5 事件）。

**科学问题**：把注水效应的观测窗口从 30 天日尺度拉到月尺度后，注水对邻井产液速率与含水率的因果效应是否变得可识别；如果可识别，它的滞后结构（峰值滞后与累计效应）是否与 CRM 的一阶低通响应 (f_ij/τ_i)·exp(−ℓΔt/τ_i) 一致？

### 数学形式化

**符号**。月 m=1..104（2008-02 ~ 2016-12）。注水井 j∈{F-4, F-5}，w_{jm}= 该月注水量 Sm³。生产井 i，月度速率口径（开井小时加权）：
  q^L_{im} = Σ_{t∈m} (V^o+V^w)_{it} / Σ_{t∈m} H_{it}
  f^w_{im} = Σ_{t∈m} V^w_{it} / Σ_{t∈m}(V^o+V^w)_{it}

**分布滞后因果模型（每个产井 i、每个注井 j）**：
  Y_{im} = Σ_{ℓ=0}^{L} β_{ijℓ} · w_{j,m−ℓ} + g_i(X_{im}) + ε_{im},   L = 12 个月
  X_{im} = {Y 的滞后 1..3、该井月度油嘴中位、月度 p_wf、累计产油、时间指标、另一口注井的同期与滞后注水量}
待估量：脉冲响应 {β_{ijℓ}}、累计效应 B_{ij}=Σ_ℓ β_{ijℓ}、峰值滞后 ℓ*_{ij}=argmax_ℓ β_{ijℓ}。
用 DML 正交化：对每个滞后 ℓ 分别构造 r^w_{ℓ} = w_{j,m−ℓ} − Ê[w_{j,m−ℓ}|X]，r^Y = Y − Ê[Y|X]，按月度连续块交叉拟合（K=4，embargo = L 个月）。

**可识别性审计（本提案的第一产出）**。定义激励比
  ρ_j = Var(w_{jm} − Ê[w_{jm}|X_{m}]) / Var(w_{jm})
即 treatment 在条件化状态后还剩多少变异。**已实测：月度全场注水对过去状态的块 CV R² = 0.009，ρ ≈ 0.99**（残差 sd 占总 sd 的 99%）。这说明注水在月尺度上近乎条件外生——即 E1–E3 的零结果**不是识别性问题，而是 horizon 问题**。同时报 CRM 设计矩阵的条件数、CRM 参数多初值重启的解离散度、以及 profile-likelihood 区间。

**CRM 结构对照（物理参数化基线）**：
  τ_i dq^L_i/dt + q^L_i = Σ_j f_{ij} w_j − τ_i J_i dp_wf,i/dt,  s.t. f_{ij}≥0, Σ_i f_{ij} ≤ 1, τ_i>0
离散解给出脉冲响应 β^{CRM}_{ijℓ} = (f_{ij}/τ_i)(1−e^{−Δt/τ_i}) e^{−ℓΔt/τ_i}。
**过约束检验**：非参估的 {β̂_{ijℓ}} 与 CRM 的单调指数衰减形状是否一致？检验 H0: β̂ 落在 CRM 的两参数族内（形状检验，非嵌套模型比较用 Vuong 或 bootstrap 形状距离）。

**F-5 停注自然实验（中断时间序列）**：2016-04 起 F-5 注水从 ~140k Sm³/月 断崖至 20k → 0（实测：2016-03 139,811 → 2016-04 20,227 → 2016-05 起 0），同期 F-4 补偿性上调（141k → 220k → 269k）。因此这是一次**总量近似守恒、空间分配剧变**的干预，恰好是 CRM 的 f_ij 所刻画的量。用中断时间序列 / 合成控制估各生产井的响应。

### 数据映射

**唯一必需数据源**：同一份 daily_production.csv 按月聚合（`_data/volve_causal_v0.2/monthly_production.csv` 已存在，但需核对其聚合口径是否为速率）。

**月度聚合规则（关键）**：q^L 与 f^w 均为「月内体积之和 / 月内开井小时之和」，即开井小时加权的月平均速率。
**关井日**：ON_STREAM_HRS=0 的日子对分子与分母**同时贡献 0**，因此自动被正确排除在速率之外；这与 P1/P2 的日尺度处理一致，且是月度聚合下唯一正确的口径（简单地对日体积求和再除以日历天数就会把停机率混进速率，这正是 CNN-LSTM-SA / Bakken-DNN 踩的坑）。
**缺日**：分子分母都跳过，但需额外记录每月的有效天数 n^{eff}_{im}，凡 n^{eff} < 10 天的井·月整体丢弃，并把 n^{eff} 作为观测权重进 DML。
**整月关井**：分母为 0 → 该井·月速率为 NaN，丢弃但记录（不能当 0）。

**记账恒等式陷阱：不落在里面。** 处理是注水量（另一口井的量），结果是本井速率或含水率；开井小时在结果量中已被除掉；X 中不含未来信息。注意一个需要防的近亲：不要用「月产液体积」当结果，否则月内停机天数会主导。

**规模实测**：104 个有效月；F-4 有注水的月 102、F-5 有注水的月 93；月度注水 CV：F-4 0.46、F-5 0.58（激励并不平坦，好消息）。生产井月度流动 p_wf 覆盖 224 个井·月（F-14 97 / F-11 39 / F-12 33 / F-15D 30 / F-1C 25）；关井恢复压力仅 87 个井·月（太稀疏，只能作辅助）。
**VRR 实测**：月度注采比中位 1.12，92% 的月份 >1，即长期超注、压力被维持——这是一条必须写进讨论的物理背景（压力被维持意味着注水的效应更多体现在扫油效率与含水率上，而非压力支撑上）。

**参数量核算（CRM 充分性判据 L=N_t·N_prod/N_par ≥ 4）**：CRMP 未知数 = 5×(2+1+1)=20，数据 224 井·月 → L≈11 > 4，勉强够。分布滞后模型每个 (i,j) 对有 13 个 β，2 个注井 → 每井 26 个参数 vs 该井 25–97 个月，**F-14 之外的井都不够**，必须做参数收缩（对 ℓ 加平滑/单调衰减先验，或直接用 CRM 的两参数族约束）。这一条是本提案最硬的技术约束。

### 候选模型

DML 分布滞后（HistGradientBoosting nuisance，月度块交叉拟合）；Local Projection（Jordà）估脉冲响应，配 Newey-West / block bootstrap；带单调衰减约束的岭回归 / 贝叶斯 shrinkage 先验（Almon 多项式滞后或指数衰减参数化）以对抗参数量不足；CRM（CRMP，约束 NLS + 多初值重启）作为结构基线；F-5 事件用 CausalImpact 型贝叶斯结构时间序列或 synthetic control（供体池只有 4 口其他生产井，需明说这是弱合成控制）。

### 验证方案

**(1) 平凡基线（强制）**：persistence（Y_{im}=Y_{i,m−1}）、井月度历史均值、「按固定比例劈分场级注水量」这一恒等式基线（CRM 综述里 BCM 的平衡约束本身就接近这个恒等式，必须单独打出来）。任何滞后效应必须在打赢这三者之后才算数。
**(2) 可识别性审计作为独立结论**：报告 ρ_j（已实测 ≈0.99）、CRM 设计矩阵条件数、多初值重启的 f_ij 解离散度。若 f_ij 的多解离散度很大而 ρ 又很高，说明限制来自参数量而非激励——这个区分本身就是文献里没人做过的诊断，即使主效应估不出来也是可发表的方法学结论。
**(3) 安慰剂 / 负对照**：用**未来**注水量 w_{j,m+ℓ}（ℓ>0）估同一模型，系数应为 0（反向因果检验）；把注水序列做块置换（保留自相关）后重估，得零分布。
**(4) 留出期**：用 2008–2013 估 β，在 2014–2016 做样本外脉冲响应预测检验。
**(5) 自然实验（核心独立验证）**：F-5 停注（2016-04）。非参估出的 β_{F-5,i,ℓ} 应能**定量预测**该事件后各生产井的响应轨迹。这是把「用平滑变异估的效应」拿到「一次剧烈阶跃」上做外推检验，是真正独立的验证。同理可用 2008-08 F-5 启注（此时 F-4 已注水 4 个月，F-12/F-14 在产，后续期长达数年，比停注事件更干净）。
**(6) 数值模拟（可选加分）**：OPM Flow 的 do(injection) 双臂给 ground truth 的 f_ij 与 τ_i。

### 可行性

**中。** 月度聚合、可识别性审计、VRR 统计、F-5 事件的原始数字本轮已全部实测。数据完全来自已加工的 CSV，不需要任何未加工资产即可完成 (1)–(5)。

**额外工作量**：(a) 月度速率口径的聚合与有效天数权重，1 天；(b) 分布滞后 DML + 收缩先验，3–5 天；(c) CRM 实现（约束 NLS + 多初值），3–5 天，无现成可复用代码；(d) F-5 事件的合成控制，2 天。共约 2–3 周。

**硬卡点，必须诚实列出**：
(1) **只有 2 口注水井**（清单第 6 条）。CRM 的核心科学产物是 I×K 连通图，靠 Σ_j f_{ij}=1、λ-距离单调、对称性这些多井统计自证；2×5=10 个注采对根本支撑不起这些判据。所以本提案**不能主张「反演出了井间连通性」**，只能主张滞后结构与可识别性。
(2) **F-5 停注的后期太短**：F-14 产到 2016-07、F-12 到 2016-08、F-11 到 2016-09，即事件后仅 3–5 个月，且与全场关停混杂。2008-08 启注事件更可用。
(3) **无 PVT**（清单第 3 节明写未确认），无法把地面 Sm³ 折到油藏条件，CRM 的 τ = c_t·V_p/J 失去绝对物理量纲，只能作相对比较；Bo/Bw 会被吸收进 f_ij 的尺度，破坏 Σf≤1 的物理解读。
(4) **井位坐标未提取**（在 `Volve_Well_technical_data.zip`, 222MB, 未加工）。CRM 拟合本身不需要坐标，但连通性的地质解释需要。解压 + 提取井头坐标预估 1–2 天，属可选。
(5) 井集在 2013-07(F-11)、2014-01(F-15D)、2014-04(F-1C)、2016-04(F-5 转产) 变了四次，CRM 要求评估窗口内井集恒定 → 必须切成多个窗口，每个窗口的 N 都被进一步压缩。

### 新意

**新意有两处，且第二处更值钱。**
(1) **把 E1–E3 的零结果重新定性。** 我们此前报「注水效应在 30 天日尺度不可观测」，容易被读成「注水没效应」或「数据不够」。实测 ρ≈0.99（注水对过去状态几乎不可预测）直接排除了识别性解释——treatment 在月尺度上近乎条件外生。这把一个负结果转成一个有明确诊断依据的正命题：**限制来自 horizon 与参数量，不来自混淆。** 16 篇里没有一篇做过这种诊断，CRM 综述只是口头承认「信号要富」。
(2) **非参脉冲响应 vs CRM 一阶低通响应的形状对拍。** CRM 三篇（Yousef 2006、Sayarpour 2009、综述）都把 τ 与 f_ij 当物理量用，却从未有人检验过「真实数据的滞后结构确实是单指数衰减」这个 CRM 的核心结构假设。我们可以用不施加该结构的估计量去检验它。
**没有新意的部分要说清**：分布滞后 / Local Projection / 中断时间序列都是标准计量工具；CRM 是 2006 年的成熟方法。我们不发明方法，只是第一次把可识别性诊断和结构假设检验带进这个数据集。

### 风险

(1) **参数量不足是最可能的死因。** 除 F-14（97 个井·月）外，其余 4 口井只有 25–39 个月，而每口井 2 个注井 × 13 个滞后 = 26 个 β。即使加收缩先验，CI 也可能宽到全部覆盖 0，得到「仍然测不出来」的第二次零结果。这次的零结果会比 E1–E3 更有信息量（因为附带了 ρ≈0.99 的诊断），但仍然难卖。
(2) **VRR>1 的物理背景可能意味着效应本身很小。** 长期超注、压力被维持，则注水的边际效应主要体现在扫油效率和含水率演化上，而这些是年尺度的累积量，在 104 个月里可能只表现为一条被时间趋势吞掉的缓慢曲线，与「时间」共线到无法分离。
(3) **F-5 停注事件与全场关停完全混杂**，合成控制的供体池只有 4 口井且它们同期也在关停，几乎不可能做出可信的反事实。若把宝押在这个事件上，风险很高；2008-08 启注事件更可靠但当时只有 2 口生产井在产。
(4) 若最终只能报可识别性审计而报不出效应量，论文的科学分量会明显低于 P1/P2。

## 综合推荐（子智能体意见）

**只能选一个就选 P1（油嘴的因果剂量-响应 + IPR 过约束检验），并把 P2 作为同一篇论文的第二个实验。**

理由，按权重排：

**1. 它已经有一个真实、量化、可复现的核心发现，本轮就跑出来了。** 合并数据的朴素斜率 dq/d(油嘴) = **−0.084 Sm³/hr 每 %**，F-14 单井朴素 = **−1.331** —— 开大油嘴产量下降，物理上不可能。做完块交叉拟合的 DML 后，五口井对产液速率的效应**全部为正**（+0.15 到 +2.48）。也就是说：**在这个数据集上，不做因果校正的估计量会违反一个连本科生都知道的物理约束，而 DML 修复了它。** 这是一个自带动机的论文开头，不需要靠「我们的 RMSE 低 0.2%」来立论。

**2. 它是唯一一个不依赖任何未加工资产、也不依赖 OPM Flow 的方案。** P1 的五层验证里前四层全部只用 `_data/volve_causal_v0.2/daily_production.csv`。清单已明写 Eclipse deck「未解压、可行性未验证」，而 E1–E3 findings 又指出它是「整个课题最大的未验证前提」。把主线押在未验证前提上是不可接受的风险；P1 把模拟器降级为可选加分层，这一点决定性。

**3. 它避开了本项目已经栽过的坑，而且是结构性避开而不是靠纪律避开。** 目标量 q^L = 体积/开井小时，H 在定义里就被除掉；处理是油嘴而非开井时长；X 全部是滞后量。P2 的主结果 f^w = V^w/(V^o+V^w) 更彻底——H 在分子分母精确抵消，数学上与开井时长无关。撤稿那次的失败模式在这两个设定下不可能重演。

**4. 它带来的方法学贡献恰好补上这批文献最大的两个空。** 16 篇里没有一篇做因果效应估计，也没有一篇给出**会失败的**验证判据。P1 的 IPR 过约束检验 θ^L/θ^{Δp} = J 已经在实测中 5 口井失败了 4 口（F-12 通过：6.87 vs 6.20；F-11 符号都错：−2.36 vs 1.19），而失败模式又能被「该井的关井恢复压力覆盖月数」解释（F-11 只有 9 个月）。一个能失败、失败还能追根因的检验，比 CRM 那种「对了算验证、错了有三条备选解释」的可证伪性高一个量级。

**5. 样本量与它的科学主张匹配。** P1 有 5,337 个井·天且逐井估计（不做跨井 pooling，尊重清单第 6 条硬限制）；重叠性已实测非退化（R²(D|X)=0.880，残差方差占 12%）。相比之下 P3 的核心卡点是参数量不足（除 F-14 外每口井只有 25–39 个月，却要估 26 个滞后系数），有相当概率给出第二次零结果。

**关于组合**：P1 与 P2 应当写成一篇。二者共用同一套识别框架（正交化 + 时间块交叉拟合 + 物理过约束 + 强制平凡基线），处理的是同一个油田上两类真实的操作干预——**连续的（油嘴）与离散的（关井）**，且各自都有一个独立于模型的物理检验（IPR 一致性 / 停井前安慰剂漂移 = 0）。P2 的初步结果（长停井造成 ~11 个百分点含水率抬升，p=0.0032，安慰剂全零）本身足够反直觉，是很好的第二个实验，但它只有 24 个长停井事件、且 17 个来自 F-1C 一口井，独立成篇的统计基础太薄。

**P3 建议降级为讨论章节或后续工作**：把已实测的 ρ≈0.99（月度注水对过去状态的 CV R² = 0.009）与 VRR 中位 1.12 写进 discussion，用来把 E1–E3 的注水零结果从「测不出来」精确化为「不是混淆导致的，是 horizon 与参数量导致的」。这是一个有价值、成本近零的澄清，但不值得赌一整个项目周期。

**动手前必须先跑的三件事**（任一失败就要重新评估）：① P2 的 leave-one-well-out——去掉 F-1C 后含水率效应是否还在；② P1 的「随机 K 折 vs 时间块折」对照——量化序列泄漏，这是我们对 Chernozhukov 的具体扩展，若两者无差别则该卖点消失；③ 用更认真的方法重估 p_res（当前的 365 日滚动中位数太粗），看 IPR 过约束检验的通过率是否改善。
