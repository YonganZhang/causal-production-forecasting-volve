# 记账恒等式陷阱

**一句话**：当预测目标 Y 与某个输入 X 之间存在近似恒等式，把 X 的未来值当协变量喂进模型，模型会以**记账**方式获得巨大提升，看起来像发现，实则什么都没学到。

## 判据（怎么识别）

出现下面任意两条就要警惕：

1. **单变量吃掉绝大部分收益**。消融显示某一个协变量单独就拿到 ≥80% 的提升——因果关系很少这么干净，恒等式才这样。
2. **提升幅度大得不合常理**。领域里 SOTA 之间差几个百分点，你的方法一下好 40%。
3. **目标是"量"而不是"率"**。体积/总量/累计类目标通常 = 强度 × 时长，时长往往就是那个恒等式变量。
4. **写不出机理**。说不清"为什么知道 X 会让 Y 更准"的物理链条，只能说"信息更多了"。

## 处置

1. **写出那条恒等式**，然后把它实现成一个**平凡基线**（几行算术，不训练）。
2. **让模型跟这条基线对拍**。打不过 = 没有证据，不管 MAE 降了多少。
3. **把恒等式变量除掉**，在剩下的物理量上重做实验。因果主张只在这个口径上成立才算数。
4. **把基线钉进代码**，加回归测试，不许后人省略。

## 本项目实例（2026-08-06）

- 恒等式：`日产油体积 ≈ 每开井小时产油率 × 当日开井小时数`（开井小时=0 的日子产油=0 占 **99.87%**）
- 错误结论：「干预条件化让 MAE 从 147.3 降到 85.2（−42%）」
- 对拍结果：三行算术的恒等式基线 MAE **81.67**，反而更低 → 结论作废
- 除掉记账项后的真相：Chronos-2 纯历史比平凡基线好 10.5%；知道未来油嘴只多 2.7%；未来注水**完全测不出**
- 落地：`_code/baselines.py::identity_rate_x_hours` 为强制对照，`run_experiment.py` 自动打 `verdict`，`_tests/test_harness.py` 有回归测试

## 同类推广

这个陷阱不限于油气。任何"总量 = 速率 × 时长/次数"的场景都适用：
电量 = 功率 × 时长、销售额 = 客单价 × 订单数、播放量 = 时长 × 并发。
凡是把"时长/次数"的未来值当已知协变量的预测任务，都要先写恒等式基线。
