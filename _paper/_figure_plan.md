## Fig. 1 —— Gaia 分层架构(**待画**)

**要让读者一眼看懂:14 个 Agent、5 层、谁有什么权限。**

版面:整页宽、纵向 5 层 + 回流箭头。每层标出该层的 Agent 与实测开销。

```
 L1 数据   ┌ data_engineer   原始 deck → 7,400+500 结构化算例(1 min/算例)
           └ cartographer    471 算例 → 4×22 影响矩阵(条件数 2.05,自报可信度)
                     │
 L2 知识   ┌ knowledge_curator   deck 审计(有 PERMX/PORO;**无 GEOMECH/STRESS**)
           │                     + 本油田文献检索(Norne 4D 地震 DOI)
           └                     → 七份知识库,每份写明**该角色没有什么证据**
                     │           〔离线执行一次,各次实验原样消费〕
 L3 推理   ┌ 7 个领域角色  各读各的切片 → 互相质疑
           └ synthesizer   按**证据强度**裁决(实测 > 文献,不按人头)
                     │  候选 θ ∈ R^(6×4)
 L4 评估   ┌ surrogate            18.1 µs/方案(3.3×10⁶ 倍)—— **只筛不判**
           └ feasibility_auditor  算术闸门 —— **刻意不交给语言模型**
                     │  幸存候选
 L5 裁决     OPM Flow 全物理  ——  唯一有权赋值,**不是 Agent**(2.7 次/实验)
                     └──────────► 实测结果回流为下一轮各角色的输入
```

识图条件与配色约定:
- **三种权限必须用三种视觉编码**,这是全文的核心主张:
  代理层(有速度无赋值权)虚线框;语言智能体(有推理无否决权)常规框;
  L5(有赋值权)实线粗框 + 强调色。
- **L2 要标"离线执行一次"**,不能画成回路里的一环 —— 那是我们没做的事。
- 回流箭头必须画出来,否则读者会把它当一次性流水线。
- 每层标**真实开销**:1 min/算例 · 18.1 µs/方案 · 2.7 次真模拟/实验。
- 不要画成"七个小人开会"。角色是**证据切片 + 知识库**,用切片名而非头像。
